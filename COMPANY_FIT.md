# Cryspike — Company and Team Fit

These are possible skills/employer matches, not known product use or endorsement.

## Project thesis

A small monitor that looks for unusually high GPU use while the rest of the computer appears idle, then reports processes worth checking.

## NVIDIA

**Relevant public technical areas:** GPU telemetry, drivers and systems software.

**Potential roles:** Systems Engineer, GPU Software Engineer, Endpoint Security Engineer, Observability Engineer or Security Research Engineer.

**Evidence to build:** Lightweight host-monitoring tool sampling GPU and CPU utilization over repeated intervals, with thresholds, exclusions, process listing and optional webhook notifications. High GPU use with low CPU is only a suspicious signal; games, rendering, video, ML workloads and drivers can create false positives. It does not prove cryptomining or malware.
